🚀 Quick Start Guide

  1. Choose your preferred documentation viewer below (Swagger UI recommended for testing)
  2. Register a test account using POST /api/v1/auth/register
  3. Login to get your JWT token using POST /api/v1/auth/login
  4. Click "Authorize" and enter your token as: Bearer YOUR_TOKEN
  5. Start testing all API endpoints interactively!
